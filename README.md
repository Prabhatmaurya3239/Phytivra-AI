# Phytivra-AI 🌱

Phytivra-AI is an AI-powered mobile application that helps farmers identify crop diseases from leaf images and provides intelligent treatment recommendations using Machine Learning and Agentic AI.

## Features

- Crop disease detection from leaf images
- AI-powered treatment recommendations
- Pesticide information
- Organic treatment suggestions
- Hindi & English language support
- Follow-up questions for low-confidence predictions

## Tech Stack

### Frontend
- Flutter

### Backend
- Django
- Django REST Framework

### Machine Learning
- TensorFlow / PyTorch

### Agentic AI
- LangGraph (Under Evaluation)

### Database
- PostgreSQL
